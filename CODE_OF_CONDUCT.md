# Code of conduct

This project welcomes everyone who wants to use or improve Keyboard Layout Fixer, whatever their
language, background, religion or level of experience.

## Our standards
- Be respectful and patient; assume good intentions.
- Give and accept constructive criticism about the work, never about the person.
- Keep discussions on topic and useful for other users.
- Respect privacy: never publish someone else's personal information, and never paste personal
  text or passwords in issues.

Not acceptable: insults, harassment, discrimination, threats, sexual content, spam or advertising,
and publishing private information without permission.

## Enforcement
The maintainer may edit or remove comments, issues and pull requests that do not follow this code,
and may block repeated offenders. Report a problem privately to the maintainer through the contact
details on the [maintainer's GitHub profile](https://github.com/breslev558); reports are handled
confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
