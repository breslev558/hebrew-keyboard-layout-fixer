# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org) (once the project is accepted; until then the public releases are not signed).

- Only the files built by GitHub Actions from this public repository (`.github/workflows/release.yml`) are signed; every release is approved by hand before signing.
- Roles: committer, reviewer and approver: [breslev558](https://github.com/breslev558) (multi-factor authentication enabled).
- Privacy: no telemetry. This program sends information to a networked system only in two optional cases: the daily update check, which only asks GitHub for the latest release of this project (no identifier), and anonymous problem reports, sent only with the user's consent (a click after an error, or the opt-in setting "Send reports without asking", off by default). A report contains only technical fields (report type, program version, Windows build, result, action, failed step, step timings, program name and window classes, kind of selection, number of characters) and the optional comment the user writes and sees before sending; never typed or copied text, no file path, no identifier. The receiver (a Cloudflare Worker) does not store IP addresses and deletes reports after 90 days. The optional "fix while typing" (off by default) watches the keys only while it is switched on, keeps only the last few words in memory, never writes or sends them, and downloads its signed word lists once from this repository when switched on. Updates can be switched off in the tray menu; reports are never sent without a click unless the user opted in, and "Never offer a report" stops the offers. Both are disabled when an administrator manages the PC.
- System changes: the installer copies the program to the user's folder, adds it to the user's startup programs and to Windows "Installed apps"; Uninstall removes all of it.
