Typed akuo instead of שלום? Press F10.

A tiny Windows 10/11 app that fixes text typed with the wrong keyboard layout: Hebrew ⇄ English, also French AZERTY, and text typed with Caps Lock on.

Download for Windows

Free and open source (MIT) · no administrator rights · all downloads and checksums · source code

F10

Typed with the English layout by mistake…

One key

Select the text and press F10. With nothing selected, the line is fixed from the cursor back to its start. F9 fixes Caps Lock mistakes.

Private

What you type is never sent or written to disk. Your clipboard is put back after each fix.

Small and fast

One native executable written in Rust, no runtime, a few MB of memory. Native ARM64 build too.

Safe updates

Optional, signed one-click updates, checked by Windows cryptography before anything is replaced.

In your language
